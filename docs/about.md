# About Tulip

Tulip is an independent Linux kernel engineering project created and maintained by haniffzain.
Contact: haniffsp@proton.me

Tulip is built directly on the upstream Linux kernel created by Linus Torvalds and developed by the Linux kernel community.

Public project home: haniffzain/tulip-linux-kernel
Engineering source: haniffzain/tulip-kernel
Upstream Linux: torvalds/linux

Tulip is not a replacement for Linux and does not claim authorship of upstream Linux source.
